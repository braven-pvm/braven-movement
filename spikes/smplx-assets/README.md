# SMPL-X model files go here

They are not in this repository and must not be committed. The licence does not
permit redistribution, and a shared repository holding them is a breach on its
own.

## Getting them

1. Register at https://smpl-x.is.tue.mpg.de and accept the licence.
2. Download the SMPL-X model. `SMPLX_FEMALE.npz` is the one the figures need.
3. Put it in this folder.

`smplx_body.py` says the same thing if you run anything that needs it before
the file is here.
